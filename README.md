# Cybersecurity Awareness Campaign

This project was created as part of a cybersecurity awareness campaign to demonstrate the risks of scanning unknown QR codes. Participants scanned what appeared to be a harmless QR code, which redirected them to a webpage displaying a security awareness message reminding users to think before opening unknown links. The goal was to encourage safe browsing habits and highlight how attackers can use seemingly innocent QR codes to deliver malicious websites or phishing attacks.
